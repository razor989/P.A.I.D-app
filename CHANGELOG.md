# Changelog

All notable changes are recorded here. Versions follow [Semantic Versioning](https://semver.org).

## [1.0.1] (2026-11-08)

### Fixed
- Android: tapping a button, cover or control no longer flashes a translucent blue box over it. The app's own pressed and selected states and the keyboard focus outline are unchanged.

## [1.0.0] (2026-11-08)

The first public version.

- Three competencies, each with four activities (Prepare, Explore and Learn, Apply, Check and Transfer): **Overtime Pay**, **Percentage Change** and **Commission**.
- Learning Library with activity galleries, floating lesson navigation and motion that respects reduced-motion settings.
- Saved progress with recovery at startup.
- Phone layouts for portrait and landscape.
- Optional interface sound.
- Android app (Capacitor 8) with native progress storage, hardware Back and its own launcher icon.

Development before this release is summarized in [docs/PROJECT-HISTORY.md](docs/PROJECT-HISTORY.md).
